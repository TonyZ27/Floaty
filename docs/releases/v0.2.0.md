# Floaty v0.2.0

## Highlights

### Window-bound Notes for macOS

Floaty notes can now be attached to one exact application window. A bound note keeps its own position and size while remaining with its target window's context, including full-screen Spaces.

- Choose a target from the note header using application name, icon, and window title.
- Keep several notes attached to the same window, each at its own saved position.
- Minimize, restore, manually hide, rebind, or unbind notes without losing their content or intent.
- Manage bound notes from the menu bar, including notes whose target window has closed or needs to be reconnected.
- Notes stay above the exact focused target window, but return to normal layering when you work in another app or another window from the same app.

Window binding is intentionally exact: Floaty never guesses that a newly opened or similarly titled window is the original target.

### Privacy and Permissions

Window binding uses macOS Accessibility permission to identify and observe the selected window. Floaty does not request Screen Recording permission, take screenshots, or read or store application content.

### A Better Note and Editor Experience

- Rename notes and collapse them while preserving their saved size.
- Create nested ordered and unordered lists with Tab and Shift-Tab.
- Use improved formatting controls, task checkboxes, and empty-line editing tools.
- Enjoy a refreshed glass-inspired visual style across notes, search, preferences, and time selection.

### Reliability Improvements

- Recover bound notes safely after display changes.
- Restore the original window layering whenever a target loses focus, is hidden, minimized, closed, or unbound.
- Recheck the live focused window before changing note layering, so quick app and window switches do not leave a note globally on top.

## Compatibility

v0.2.0 releases are available for Apple Silicon Macs only. The downloadable `.dmg` is the standard installation package; signed update assets are also included to support Floaty's in-app updater.

Window-bound Notes require Accessibility permission and are available on macOS only.
