# Floaty v0.3.0

## Highlights

### Custom Keyboard Shortcuts
Floaty now supports customizable keyboard shortcuts:
- Record and configure custom key combinations in Preferences.
- Supports shortcuts for:
  - Global new note creation
  - New note when focused
  - Hide current note
  - Toggle always-on-top pin
  - Open/close appearance settings
  - Delete current note
- Built-in conflict detection and easy one-click reset to defaults.

### Priority & Quick Insert Picker
- Assign priority levels to notes and tasks.
- Improved quick insert menu with keyboard navigation.
- Enhanced `@` interaction for scheduling and due dates.

### Window Management & Editor Enhancements
- Modal windows now support smooth resizing.
- Improved text ligature rendering and typography experience.
- Pinned notes remain visible across macOS Spaces.

### In-App Updater & Stability
- Integrated desktop in-app updater capability for seamless updates.
- Performance and layering optimizations for macOS window-bound notes.

## Compatibility

v0.3.0 releases are available for Apple Silicon Macs (macOS 14+). The downloadable `.dmg` is the standard installation package.
